# Capacitação Java - Minsait
 
## Sobre o projeto
 
Este foi um dos meus primeiros projetos desenvolvidos durante minha jornada de aprendizado em programação.
 
O repositório reúne exercícios, exemplos e práticas realizados durante a capacitação Java da Minsait, contribuindo para o desenvolvimento da minha lógica de programação e dos meus conhecimentos em desenvolvimento de software.
 
## Tecnologias Utilizadas
 
- Java
- Git
- GitHub
 
## Objetivos de Aprendizagem
 
- Compreender a lógica de programação
- Praticar conceitos fundamentais de Java
- Desenvolver habilidades de resolução de problemas
- Utilizar controle de versão com Git
 
## Minha Evolução
 
Este projeto representa uma etapa importante da minha trajetória de aprendizado. Ele marca meus primeiros contatos com programação e serve como registro da minha evolução como desenvolvedora.
